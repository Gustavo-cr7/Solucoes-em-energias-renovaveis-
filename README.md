# Space Energy Monitor

Projeto desenvolvido para a Global Solution da disciplina Soluções em Energias Renováveis e Sustentáveis.

## Descrição

O Space Energy Monitor é um sistema simples de monitoramento de uma missão espacial experimental. Ele simula dados operacionais de módulos da missão, como temperatura, energia, geração, consumo, comunicação e status.

O objetivo é identificar situações críticas e gerar alertas automáticos para apoiar a tomada de decisão básica durante a operação.

## Objetivo do Projeto

Analisar dados simulados de sistemas energéticos de uma missão espacial, aplicando conceitos de energia, potência, sustentabilidade e monitoramento inteligente.

## Funcionalidades

- Simulação de dados dos módulos da missão
- Monitoramento de temperatura
- Monitoramento de energia disponível
- Análise de geração e consumo de energia
- Verificação de comunicação
- Verificação do status dos módulos
- Geração automática de alertas
- Exibição dos dados em tabela

## Módulos Monitorados

- Painel Solar
- Bateria Central
- Comunicação
- Controle Térmico
- Suporte de Vida
- Propulsão

## Alertas Gerados

O sistema pode gerar os seguintes alertas:

- Sistema normal
- Temperatura crítica
- Energia baixa
- Módulo offline
- Falha de comunicação

## Tecnologias Utilizadas

- Python
