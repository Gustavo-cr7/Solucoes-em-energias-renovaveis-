## Descrição

O Space Energy Monitor é um sistema de monitoramento desenvolvido para uma missão espacial experimental. O programa simula dados operacionais dos módulos da missão e realiza análises simples relacionadas à temperatura, energia, comunicação e status dos equipamentos.

Com base nos dados gerados, o sistema identifica situações críticas e apresenta alertas automáticos para auxiliar no monitoramento da operação.

## Objetivo do Projeto

Desenvolver uma solução capaz de monitorar sistemas energéticos de uma missão espacial experimental, aplicando conceitos de energia, potência, sustentabilidade e tomada de decisão básica.

## Funcionalidades

- Simulação de dados operacionais dos módulos
- Monitoramento da temperatura dos sistemas
- Monitoramento da energia disponível
- Controle de geração e consumo de energia
- Verificação da estabilidade da comunicação
- Verificação do status dos módulos
- Geração automática de alertas
- Exibição dos dados em formato de tabela
- Resumo geral da missão

## Módulos Monitorados

- Painel Solar
- Bateria Central
- Comunicação
- Controle Térmico
- Suporte de Vida
- Propulsão

## Alertas Gerados

O sistema pode identificar as seguintes situações:

- Sistema normal
- Temperatura crítica
- Energia baixa
- Módulo offline
- Falha de comunicação

### Instalar a biblioteca necessária

```bash
pip install pandas
```

### Executar o programa

```bash
python main.py
```

## Exemplo de Funcionamento

O sistema gera valores aleatórios para cada módulo monitorado e apresenta:

1. Tabela contendo todos os dados da missão.
2. Lista de alertas identificados.
3. Resumo geral da missão com:
   - Quantidade de módulos monitorados;
   - Quantidade de alertas encontrados;
   - Energia média dos módulos.

## Impacto da Solução

O monitoramento energético é essencial para garantir a segurança e a eficiência de missões espaciais. A identificação antecipada de falhas em módulos críticos permite reduzir riscos operacionais e melhorar o gerenciamento dos recursos energéticos disponíveis.

## Conclusão

O projeto demonstra a aplicação de conceitos de programação e monitoramento inteligente para análise de sistemas energéticos em missões espaciais. A solução permite organizar informações operacionais, gerar alertas automáticos e fornecer uma visão geral da situação da missão de forma simples e eficiente.
